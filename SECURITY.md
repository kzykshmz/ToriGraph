# Security Policy

## Supported Versions

Only the latest release / `main` branch of ToriGraph is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in ToriGraph, please report it via GitHub Security Advisories on this repository:

- https://github.com/kzykshmz/ToriGraph/security/advisories/new

For non-sensitive bugs or general issues, please open a GitHub Issue at:

- https://github.com/kzykshmz/ToriGraph/issues
