ToriGraph Quick Guide

Fast scientific plotting, materials & curve analysis, 600 DPI journal formatting, and editable PowerPoint OLE slides on Windows.

Home Plot Materials Analysis Worksheet Format & Export Tools

1. Import Data or Paste from Excel

  1. Drag & drop any Excel (.xlsx / .xlsm), CSV, or TSV file onto the ToriGraph window to open it directly (or use Ribbon Home → Import, or Import Excel (.xlsx) / CSV... in the center Welcome Hub). To paste numeric cells copied in Excel, click Home → Paste (Ctrl+V) or press Ctrl+V. When an imported CSV or Excel file changes on disk, reload it into the same worksheet via Worksheet → Re-import (or the worksheet bar Tools ▾ → Re-import from Source).
  2. After importing or pasting, double-click the Long Name, Units, or F(x)= header rows, or click Col Props above the table (or double-click a column header) to edit column metadata and axis designations. All edits support Ctrl+Z undo, and the bottom status bar shows live N / Mean / SD statistics for selected cells.

2. Plot in Two Clicks

  1. Select X/Y columns (or leave default selection to plot all Y columns against X).
  2. Click Line+Symbol or Scatter on the worksheet QuickBar, or open the Plot ribbon tab (Line + Symbol, Scatter, stacked/multi-panel plots, etc.).

3. Journal & Slide Presets + Inspector Styling

  • Journal (ISIJ 85 mm): Click ISIJ 85mm Fig on the left of the Format & Export tab, or ISIJ 85mm at the top of the right-hand Graph Inspector, to apply 85 × 85 mm sizing, Arial typography, inward box ticks, and 600 DPI defaults at once.
  • Lab Slide (18pt): Click Lab Slide (18pt) on Format & Export or in the Inspector to prepare an 83.3 mm square graph with 12.9 pt Arial. Sending it with Send to PowerPoint (default 140% paste scale) renders cleanly at 18 pt on a 16:9 slide.
  • Reference Lines & Fine Control: Add y = 0 / x = 0 or custom Reference Lines from the Inspector Axis tab, the Plot ribbon tab, or the axis mini-toolbar. Adjust axis ranges, label sizes, fractional curve widths (such as 0.5 px), colormap scatter palettes, and legends live, or click More Details... for full dialogs. New plots default to the colorblind-safe ToriGraph Default curve palette.

4. Paste or Send Editable Graphs to PowerPoint (OLE)

  1. Select a graph window and click Home or Format & Export → Copy for PowerPoint (or press Ctrl+C), then paste into PowerPoint with Ctrl+V.
  2. To build or incrementally update a .pptx deck without opening PowerPoint, click Format & Export → Send to PowerPoint. Double-click any embedded ToriGraph slide object in PowerPoint later to re-open and edit the live graph.

5. Export Images, Vector PDF, and Python Scripts

Save graphs as raster or vector images (PNG, TIFF, SVG, EMF) via Format & Export → Export (or Image / PDF Export in the Inspector). Open More Export ▾ right next to it for Copy High-DPI Image, Export PDF, and Export Python (which generates a standalone Matplotlib script plus comments noting any properties that cannot be reproduced identically).

6. Text & Canvas Annotations

  • To place a text label on a graph, click Plot → Add Text, click the target position on the canvas, and type directly.

9. Troubleshooting

Double-clicking a graph in PowerPoint does not open ToriGraph

  • Click Help → Repair PowerPoint Link (OLE Registration)..., or run the Start Menu shortcut ToriGraph → Repair OLE Server.

Stuck in Zoom or Data Reader mode

Press Esc, click Mode: ... on the bottom status bar, or click Plot → Pointer.

10. Updates, Settings Backup & Python SDK

Updates: Click Help → Check for Updates... (or Ribbon Tools → Check for Updates) to check the latest GitHub release and verify SHA-256 checksums before applying an update.

Settings Export / Import / Reset: On the Tools tab, open Settings File ▾ and choose Export Settings to save an INI backup, Import Settings to restore it on another PC (takes effect after restart), or Reset Settings to restore defaults without touching project or data files.

Python Automation SDK: The bundled torigraph Python package (documented in python/README.md) automates headless plotting, curve fitting, diagnostics, and Zero-COM .pptx slide generation via JSON-RPC 2.0.
