ToriGraph かんたんガイド

Excel のデータを貼り付けてから、論文用の体裁に整え、PowerPoint に貼り、あとで直すところまでを 1 ページにまとめました。 このページは F1 でいつでも開けます。

  1. データを読み込む・貼り付ける
  2. グラフを描く
  3. 体裁を整える (論文・研究室スライド)
  4. PowerPoint に貼る・送る
  5. ダブルクリックで直す
  6. 覚えておくと楽なキー
  7. Origin を使っていた人へ(用語の対応)

1. データを読み込む・貼り付ける

Excel ブック (.xlsx) や CSV ファイルをそのまま読み込む

  • Excel ファイル (.xlsx / .xlsm)・CSV・TSV を ToriGraph のウィンドウにドラッグ&ドロップするだけで直接読み込めます(リボンの「ホーム」→「インポート」、または初期画面右側の「Excel (.xlsx) / CSV 読込...」からも開けます)。
  • 複数シートを含む Excel ブックは複数シートのワークブックとして取り込まれ、ワークシート下部のシートタブ([Sheet1] [Sheet2] [+])で切り替えられます。「ホーム」→「その他新規」→「新しいブック」から空の複数シートブックを作ることもできます。
  • CSV・テキストファイルの区切り文字と文字コード(UTF-8、Shift-JIS)は自動で判定します。

Excel からコピー&ペースト / 長い名前と単位の入れ方

  1. Excel で表の範囲を選んで Ctrl+C でコピーし、ToriGraph のワークシート左上のセルをクリックして Ctrl+V で貼り付けます。
  2. 1 行目に長い名前(例: 公称応力)、2 行目に単位(例: MPa、%)があると自動で認識され、軸タイトル(公称応力 (MPa) や ISIJ 形式 公称応力 / MPa)および凡例にそのまま使われます。
  3. 貼り付けたあとからでも、ワークシート上部の「長い名前」「単位」行をダブルクリックするか、表右側の「列設定」パネルでいつでも入力・変更できます。

2. グラフを描く

  1. 横軸(X)にする列が左端にあれば、そのまま X として扱われます。別の列を X にしたいときは、列見出しを右クリックして「列の役割を設定」→「X」を選びます。
  2. 縦軸(Y)にしたい列の見出しをクリックして選びます(Ctrl を押しながらで複数選べます)。何も選ばなければ、すべての Y 列を描きます。
  3. リボンの作図ボタン(「折れ線 + シンボル」「散布図」など)を押します。

グラフを選んでいる状態で作図ボタンを押すと、そのグラフの元の表から新しいグラフを作ります。元の表が分からないときは、理由を画面に表示します。

3. 体裁を整える (論文・研究室スライド)

  • 論文用 (ISIJ 85 mm): リボンの「書式・出力」タブ左端、または右側のグラフインスペクタ最上段の「ISIJ 論文 (85mm)」を押すと、85 mm 角・Arial・内向き目盛り・600 dpi の 1 段組体裁に一度で揃います。
  • 研究室スライド (18pt): 「書式・出力」タブまたはインスペクタの「研究室スライド (18pt)」を押すと、83.3 mm 角・Arial 12.9 pt に整います。次の「PowerPoint へ送る」(既定 140% 倍率)でスライドへ配置すると、スライド上でちょうど 18 pt(16:9 スライドに 2〜3 枚並べても読みやすい大きさ)になります。
  • 基準線と細かい調整: インスペクタの「軸 (X/Y)」タブや軸ミニツールバーから y = 0 / x = 0 基準線をワンクリックで入れられます。軸の範囲、文字の大きさ、小数線幅、カラーマップ散布図の配色や凡例もインスペクタで即座に変えられ、右下の「詳細設定…」から全項目ダイアログも開けます。既定の曲線配色には色覚多様性とプロジェクタ視認性に配慮した「ToriGraph 標準」パレットが使われます。
  • 他のグラフと揃える: 「書式のコピー」→ 揃えたいグラフで「書式の貼り付け」。

4. PowerPoint に貼る・送る

方法 A: 開いているスライドにそのまま貼る (Ctrl+C → Ctrl+V)

  1. グラフをクリックして選び、「ホーム」タブの「PowerPoint 用にコピー」または Ctrl+C を押します。
  2. PowerPoint のスライド上で Ctrl+V を押すと、あとからダブルクリックで再編集できる OLE グラフとして貼られます。

方法 B: 「PowerPoint へ送る」で .pptx ファイルへ直接書き出す

  • リボンの「書式・出力」→「PowerPoint へ送る」(または「ファイル」メニュー)を押すと、PowerPoint を起動していなくても、選んだグラフ(複数一括も可)を新規 .pptx または既存 .pptx の末尾スライドへ編集可能な OLE オブジェクトとして直接追加できます(貼付倍率 140% なども指定できます)。

画像ファイル(PNG、TIFF、PDF、SVG、EMF)として保存したいときは、「書式・出力」→「画像出力」を使います。

5. ダブルクリックで直す

  • PowerPoint 上で: 貼ったグラフをダブルクリックすると ToriGraph が開きます。直してからウィンドウを閉じると、スライド上の図が更新されます。大きさは変わりません。
  • ToriGraph 上で: 軸タイトル・凡例・文字はダブルクリックでその場で書き換えられます。曲線と軸はダブルクリックで詳しい設定のダイアログが開きます。右のインスペクタの一覧でダブルクリックしても同じように動きます。
  • 文字を足すには「テキストの追加」を押してから、グラフ上の入れたい位置をクリックし、そのまま入力します。

8. 困ったとき(FAQ)

インストールや起動のときに「Windows によって PC が保護されました」と出る

Microsoft SmartScreen の表示です。ToriGraph は署名していないので、初回はこの表示が出ることがあります。研究室で配られたファイルであることを確かめてから、「詳細情報」→「実行」を押してください。出どころの分からないファイルは実行しないでください。

PowerPoint のグラフをダブルクリックしても ToriGraph が開かない

  1. スタートメニューの「ToriGraph」→「OLE サーバーを再登録 (PowerPoint 連携修復)」を実行します。
  2. PowerPoint をいったん閉じてから開き直し、もう一度ダブルクリックします。
  3. ポータブル版(zip)を使っている場合は、ToriGraph のフォルダで次を実行します。
    powershell -ExecutionPolicy Bypass -File scripts\register-ole.ps1 -Mode Install

開発用にビルドした別の ToriGraph を起動すると、PowerPoint の連携先がそちらに変わることがあります。そのときも上の再登録で戻ります。

貼り付けたら 1 つの列に全部入った / 列が割れた

Excel からのコピーはタブ区切りで貼り付けます。テキストエディタからコピーした場合は、区切りがタブになっているか確かめてください。CSV として保存してから読み込むと確実です。

作図ボタンを押しても何も起きない

X にする列が無い、Y の列が無い、表が空、のどれかです。画面に出る案内に従って、列見出しの右クリック(「列の役割を設定」)で X 列・Y 列を決めてから押し直してください。

ズームやデータ読取から抜けられない

Esc を押すか、画面下のステータスバーに出ている「モード: …」をクリックします(リボンの「解析」タブの「ポインタ」でも戻れます)。

保存しようとしたら失敗した

保存に失敗したときは、プロジェクトは「未保存」のままになり、閉じるときに確認が出ます。Dropbox などの同期中のフォルダでは、少し待ってから保存し直すか、別の場所に「名前を付けて保存」してください。
